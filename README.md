# 우리 뭐 먹지?

**먹고 싶은 걸 고르지 말고, 먹기 싫은 걸 지우세요.**

여러 명이 핸드폰 하나를 돌려가며 각자 "절대 먹기 싫은" 메뉴를 하나씩 지워
빠르게 메뉴를 정하는 웹서비스입니다.

**👉 https://menu-veto.vercel.app**

> 성균관대학교 「신인류 AI 사피엔스 경험디자인」 2026 여름학기 기말 조별과제 —
> 바이브코딩으로 MVP 서비스 만들기

## 왜 만들었나

여러 명이 메뉴를 정할 때 "짜장면 어때? → 별로" 하는 **제안과 거절이 반복**되며
시간이 오래 걸립니다. 이 서비스는 질문을 뒤집습니다.

- ❌ "뭐 먹고 싶어?" → 제안이 쌓이고 거절이 반복된다
- ✅ **"오늘 절대 먹기 싫은 건 뭐야?"** → 후보가 줄어들고 반드시 끝난다

**검증하려는 가설**: 전체 메뉴 중 랜덤으로 추천하는 것보다,
각자의 비선호를 먼저 제거한 결과가 **더 잘 받아들여질 것이다.**

## 어떻게 동작하나

```
① 시작       인원 선택 (2~5명)
② 제거       한 사람씩 차례로 8개 카테고리 중 하나를 지움
③ 최종 선택   남은 후보를 룰렛으로 무작위 확정
④ 결과       선택된 메뉴 + 걸린 시간 + 수용 / 거부(최대 1회)
```

후보는 개별 음식명이 아니라 **카테고리 8개**입니다.
한식 · 중식 · 일식 · 양식 · 패스트푸드 · 분식 · 가벼운 식사 · 국밥&#183;찌개류

### 일부러 넣지 않은 것

- **AI 추천 / 취향 학습** — 이 서비스의 주장은 *"AI 추천이 아니라 비선호 제거"*입니다
- **최종 선택을 사람이 직접 하기** — 마지막에 협상이 다시 시작됩니다
- 로그인, 실시간 다중 기기 참여, 지도 연동

## 실행하기

```bash
cd web
npm install
npm run dev     # http://localhost:3000
```

| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 개발 서버 |
| `npm run build` | 배포용 빌드 + 타입 검사 |
| `npm run lint` | 코드 점검 |

**모바일이 주 사용 환경입니다.** 같은 와이파이의 핸드폰에서 열어 확인하세요
(`next dev`가 알려주는 Network 주소). 사설 IP 접근은 `web/next.config.ts`에서 허용해 둡니다.

## 기술 스택

Next.js 16 (App Router) · TypeScript · Tailwind CSS v4 · Vercel

서비스 자체는 브라우저 안에서만 돌아갑니다. 서버도 DB도 필요 없습니다.
DB(Supabase)는 **가설을 검증할 기록을 모으기 위해** 나중에 붙입니다.
